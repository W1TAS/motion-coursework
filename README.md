# Движение

Курсовой проект: анализ отжиманий, планки и подтягиваний по видео.
MediaPipe определяет точки тела, а правила выделяют фазы движения,
считают повторения и проверяют наблюдаемые признаки. Оценка правильности
подтягиваний пока экспериментальная. Подъём фиксируется после прохождения
верха; начальное положение проверяется отдельно, с отказом при потере трека.
На видео голубым показаны доступные точки лица той же модели MediaPipe: нос,
глаза, уши и уголки рта. Отдельная модель лица в приложении не используется.
В подтягиваниях доступны встроенные примеры, видео из памяти устройства
и камера, фронтальная и задняя. Выбранный файл обрабатывается локально,
с паузой и перемоткой; видео на сервер не отправляется. Временное
правило высоты сравнивает рот с расчётным уровнем по кистям; его вывод можно
скрыть переключателем. Реальная перекладина и подбородок не обнаруживаются.

## Структура

| Папка | Назначение |
|---|---|
| `mobile/app/` | Веб-интерфейс, камера, скелет и обработка упражнений — JavaScript, HTML, CSS |
| `mobile/android/` | Небольшая Android-оболочка WebView — Java |
| `mobile/tests/` | Проверки логики и интерфейса |
| `mobile/research/` | Код экспериментов и сравнения алгоритмов |
| `pullups/` | Поиск видео, разметка, подготовка данных и обучение — Python |
| `scripts/` | Общие команды проверки и восстановления зависимостей |

В репозитории находятся исходники. Видео, разметка, признаки, обученные
модели, результаты экспериментов, LaTeX, PDF и APK хранятся отдельно.

## Проверки

Нужны Python и Node.js; npm-пакеты для основных проверок не требуются.

```sh
python scripts/check.py
```

Основные тесты используют искусственные примеры и не требуют датасета.
Исследовательские скрипты и отдельные браузерные проверки требуют
соответствующих локальных данных и дополнительных библиотек из
`requirements-research.txt`.

## Запуск веб-приложения

Один раз загрузить фиксированные зависимости MediaPipe с проверкой SHA-256,
затем запустить сервер:

```sh
python scripts/setup_assets.py
python mobile/serve.py --host 127.0.0.1 --port 8770
```

Открыть `http://127.0.0.1:8770/`. Для камеры нужен localhost, HTTPS или
Android-приложение; открытие `index.html` через `file://` не подходит.
Записи подтягиваний, собственный классификатор и параметры правила высоты нужно
восстановить локально; они не загружаются этой командой.

Для сборки Android: `python mobile/build_android.py --sdk /путь/к/android-sdk`.
Нужны JDK, Android platform 35 и build-tools 35.0.0. Условия сторонних
компонентов: [THIRD_PARTY.md](mobile/THIRD_PARTY.md).
